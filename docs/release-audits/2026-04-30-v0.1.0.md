# v0.1.0 Release Audit

Date: 2026-04-30

## Scope

- First public GitHub release for the Java Swing AircraftWar application.
- Release package: `AircraftWar-0.1.0.zip`, containing `AircraftWar-0.1.0.jar` and README.

## Checks

- Dependency/security review: project uses bundled JUnit 5 jars for tests and no runtime third-party dependencies.
- Test suite: command-line JUnit suite passes with 46/46 tests successful.
- Build/package verification: production classes compile with JDK tools; JAR includes `edu/hitsz/application/Main.class`, `images/hero.png`, and `videos/bgm.wav`.
- Runtime smoke: packaged JAR can load image resources from the classpath via `ImageManager`.
- Resource handling: images and audio now load from classpath first, with development file paths as fallback.
- Documentation: README documents command-line tests, release package execution, and manual JAR packaging commands.
- Content/assets: release contains course project image/audio resources already present in the repository.

## Deferred

- No installer is provided for v0.1.0; users run the JAR with a local JDK.
- GUI smoke was limited to non-window resource loading to avoid launching an interactive Swing session during automated verification.
