# v0.1.1 Release Audit

Date: 2026-04-30

## Scope

- Patch release after v0.1.0.
- Fixes restart flow after returning from the leaderboard to the difficulty menu.
- Adds a Windows x64 app-image package with `AircraftWar.exe` and bundled runtime.

## Checks

- Bug regression: `GameTest.creatingNewGameRestoresHeroAfterPreviousGameOver` verifies that a new game resets the hero aircraft after game over.
- Test suite: command-line JUnit suite passes with 49/49 tests successful.
- Build/package verification: production classes compile with JDK tools; JAR includes main class, images, and audio resources.
- Runtime smoke: packaged JAR can load image resources from the classpath via `ImageManager`.
- Windows exe package: `jpackage --type app-image` creates `AircraftWar/AircraftWar.exe` with bundled runtime DLLs and `app/AircraftWar-0.1.1.jar`.
- Documentation: README documents JAR execution, Windows exe ZIP execution, and packaging commands.

## Deferred

- A single-file Windows installer `.exe` is not included because WiX/NSIS/Inno Setup is not installed in the current environment.
- GUI smoke is limited to non-window resource loading and package structure checks to avoid launching an interactive Swing session during automated verification.
